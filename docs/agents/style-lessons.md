# Style lessons from the owner's reviews

The content agent appends to this file whenever the owner's review comments or edits reveal a **general** preference (not a one-off factual fix). These rules override `style-reference.md`.

Format: one line per lesson, newest at the bottom, with the PR it came from.

```
- <rule, phrased as an instruction> (PR #N)
```

Over time this file plus the draft → final diffs of merged PRs become HexAstro's own style dataset.
